## 운영 확인 SQL

배포하고 일괄 추출(`POST /api/admin/policy/condition/extract`)을 마친 뒤 실행한다.

```sql
-- 1. 추출 진행률과 프롬프트 버전
select count(*) total, count(condition_extracted_at) extracted,
       count(*) filter (where condition_prompt_version = 'policy-condition-v1') v1
from policy;

-- 2. 유형별 건수 (출처별)
select source, income_basis, count(*) from policy group by 1, 2 order by 1, 3 desc;
select source, housing_requirement, count(*) from policy group by 1, 2 order by 1, 3 desc;
select source, target_type, count(*) from policy group by 1, 2 order by 1, 3 desc;

-- 3. UNKNOWN 비율
select round(100.0 * count(*) filter (where income_basis = 'UNKNOWN') / count(*), 1) income_unknown_pct,
       round(100.0 * count(*) filter (where housing_requirement = 'UNKNOWN') / count(*), 1) housing_unknown_pct,
       round(100.0 * count(*) filter (where target_type = 'UNKNOWN') / count(*), 1) target_unknown_pct
from policy where condition_extracted_at is not null;

-- 4. 지역 보완 (region이 빈 정책 중 extracted_region이 채워진 건수와 목록)
select source, count(*) filter (where coalesce(region, '') = '') region_empty,
       count(*) filter (where coalesce(region, '') = '' and extracted_region is not null) region_filled
from policy group by 1;
select name, extracted_region from policy
where coalesce(region, '') = '' and extracted_region is not null order by name;

-- 5. 제외에 쓰이는 판정 샘플 (사람이 원문과 대조)
select name, income_basis, income_max_monthly, left(income_condition, 80)
from policy where income_basis = 'INDIVIDUAL' order by name;
select name, left(coalesce(eligibility_detail, description), 120)
from policy where target_type = 'BUSINESS' and source = 'YOUTH_CENTER' order by name;
select name, left(coalesce(eligibility_detail, description), 120)
from policy where housing_requirement = 'HOMELESS_REQUIRED' order by random() limit 20;

-- 6. 신청기간 구분 코드 (배포 후 첫 동기화 이후 채워짐)
select source, coalesce(apply_period_code, '(null)'), count(*) from policy group by 1, 2 order by 1, 2;
```

## 추천 전후 비교 방법 (운영)

1. 배포 **전**에 비교할 계정으로 `GET /api/policies`를 호출해 건수와 상위 10건을 저장한다
   - 조건 조합: 만 25세·만 40세 × 소득 구간(150만원 미만, 260~300만원, 410만원 이상) × 무주택·유주택 × 직장인·학생·자영업자
   - 운영 계정을 새로 만들기 어렵다면 프로필 수정 API(`PUT /users/me/profile`, API_Spec.md 2절)로 한 계정의 조건을 바꿔 가며 호출한다
2. 배포 → 일괄 추출 → (선택) 관리자 동기화(`POST /api/admin/policy/sync`)로 신청기간 구분 코드 채우기
3. 같은 계정·조건으로 다시 호출해 건수와 상위 10건을 비교한다
4. 빠진 정책은 정책 ID로 `income_basis`, `housing_requirement`, `target_type`, `extracted_region`을 조회해 제외 사유가 맞는지 원문과 대조한다
